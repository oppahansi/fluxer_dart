# Security Policy

## Supported Versions

fluxer_dart is pre-1.0 (`0.x.y`) and under active development. Only the
latest published version/commit on `main` is supported — there's no
backport policy for older `0.x` releases yet.

## Reporting a Vulnerability

If you believe you've found a security vulnerability in this repository
(as opposed to a bug in Fluxer itself — report those to
[Fluxer](https://fluxer.app) directly), please report it privately
rather than opening a public issue:

1. Preferred: use GitHub's
   [private vulnerability reporting](https://github.com/oppahansi/fluxer_dart/security/advisories/new)
   for this repository.
2. Otherwise: email oppahansi@gmail.com with details and, if possible, a
   minimal reproduction.

Please include:

- The package version (or commit) affected
- A description of the vulnerability and its potential impact
- Steps to reproduce, if available

This is a personal open-source project without a dedicated security
team, so response times aren't guaranteed by an SLA — but reports will
be acknowledged and looked at as soon as reasonably possible, and
credited in the fix's release notes unless you'd prefer otherwise.

Please don't disclose the issue publicly until a fix has been released.
